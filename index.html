DRAIN-LID Design Performance Explorer

This interactive platform maps hydrologic performance and lifecycle cost tradeoffs in infiltration-based low impact development systems. Users can explore how soil type, effective precipitation, area ratio, media depth, and inflow timing shape peak-flow attenuation, detention behavior, ponding response, and cost efficiency across the DRAIN-LID simulation database.

Physics-based database 3D design-space visualization Hydrograph inspection Cost-performance screening
Purpose

Decision support for infiltration-based LID design

The explorer was designed to support rapid interpretation of a large numerical simulation database and to help compare alternative bioretention configurations using physically meaningful hydrologic metrics and transparent cost assumptions.

How the model works

The DRAIN-LID Designer toolbox is built on a physics-based numerical framework that represents vertical water movement through engineered bioretention media, the inflow hydrograph from the contributing catchment, and the lifecycle costs of alternative designs. This interface allows users to interpret the resulting database through hydrologically meaningful metrics and cost-performance tradeoffs.

Richards-based vertical flow model

Vertical flow through the media is represented using the one-dimensional mixed-form Richards equation with pressure head \(h(z,t)\) as the primary state variable:

\[ \frac{\partial \theta(h)}{\partial t} + S_s \frac{\partial h}{\partial t} = \frac{\partial}{\partial z} \left[ K(h)\left(\frac{\partial h}{\partial z} + 1\right) \right] + S(z,t). \]

Here \(z\) is depth, \(\theta(h)\) is volumetric water content, \(K(h)\) is hydraulic conductivity, \(S_s\) is specific storage, and \(S(z,t)\) represents sources and sinks linked to drainage and exchange processes. Soil hydraulic behavior is represented through van Genuchten–Mualem constitutive relationships.

\[ \theta(h) = \begin{cases} \theta_r + (\theta_s - \theta_r)\left[1 + (\alpha |h|)^n\right]^{-m}, & h < 0,\\[4pt] \theta_s, & h \ge 0, \end{cases} \] \[ K(h) = \begin{cases} K_s \left[1 + (\alpha |h|)^n\right]^{-m l} \left\{ 1 - (\alpha |h|)^{n-1} \left[1 + (\alpha |h|)^n\right]^{-m} \right\}^2, & h < 0,\\[4pt] K_s, & h \ge 0. \end{cases} \]

The model is solved with an implicit finite-volume formulation and adaptive Newton–Raphson iteration, so each point in the database corresponds to a full Richards-equation simulation.

Design hydrograph and catchment inputs

Inflow to the LID cell is represented through a synthetic design hydrograph driven by:

  • effective rainfall depth \(P_{\mathrm{eff}}\),
  • upstream contributing area \(A_{\mathrm{up}}\), and
  • hydrograph time to peak \(t_{\mathrm{p}}\).

A Nash-type formulation is used for the inflow hydrograph:

\[ Q_{\mathrm{in}}(t) = Q_{\mathrm{p}} \left( \frac{t}{t_{\mathrm{p}}} \exp\left[1 - \frac{t}{t_{\mathrm{p}}}\right] \right)^{m-1}. \]

For each combination of \((P_{\mathrm{eff}}, A_{\mathrm{up}}, t_{\mathrm{p}})\), area ratio \(r = A/A_{\mathrm{up}}\), media depth \(L_d\), and soil type, the model routes the hydrograph through the bioretention profile.

Hydrologic performance metrics

Peak flow reduction

\[ \eta_{\mathrm{p}} = 100 \, \frac{Q_{\mathrm{p}}^{\,i} - Q_{\mathrm{p}}^{\,o}} {Q_{\mathrm{p}}^{\,i}}. \]

Time-to-peak delay

\[ \Delta t_{\mathrm{p}} = t_{\mathrm{p}}^{\,o} - t_{\mathrm{p}}^{\,i}. \]

Detention time

\[ \Delta t_{\mathrm{d}} = t\bigl(Q_{\mathrm{out}}(t) \le \tau\bigr) - t_{\mathrm{p}}^{\,i}. \]

These metrics allow users to screen feasible solutions and compare designs without rerunning the numerical model.

Lifecycle cost model

Construction and maintenance are represented using a simple but interpretable lifecycle cost framework.

Construction cost

\[ C_{\mathrm{CapEx}} = c_{\mathrm{vol}} \, A \, L_{\mathrm d} + c_{\mathrm{surf}} \, A. \]

Annual O&M cost

\[ C_{\mathrm{O\&M,annual}} = c_{\mathrm{O\&M}} \, A. \]

Present-value factor

\[ F(i,T) = \frac{1 - (1 + i)^{-T}}{i}. \]

Net present value

\[ C_{\mathrm{NPV}} = C_{\mathrm{CapEx}} + F(i,T)\, c_{\mathrm{O\&M}} \, A. \]

Modeling assumptions

  • Initial conditions correspond to an unsaturated hydrostatic profile.
  • The system is modeled as laterally lined.
  • The underdrain behaves as a free-drain boundary.
  • The vertical profile is discretized with nonuniform finite-volume nodes.
  • Hydraulic properties are homogeneous within each simulation.
  • Evapotranspiration is neglected over event-scale simulations.
  • Flow is treated as one-dimensional in the vertical direction.
